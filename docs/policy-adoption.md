# Ground Zero and Illuci

[Ground Zero](https://github.com/ellyj3rain/Ground_Zero) is the development system and framework. It owns the Constitution, Bill of Standards and reusable methods for AI-governed software development. Illuci is an engine: it owns the implementation, execution interfaces, data paths and checks that put selected practices to work.

The relationship runs in both directions. A runtime failure can reveal an imprecise standard or missing effect boundary. A refined standard can expose a weak engine consumer. Each project keeps its own source, review, release and contribution path. They are not a combined repository or a single version line.

## Explicit source receiving

[`ground-zero-source.json`](../core/governance/adoption/ground-zero-source.json) is an immutable identity record for the selected Ground Zero source. It names the documents, provision anchors and byte hashes. It is not a maintained copy of those documents and supplies no action permission. [`correspondence.json`](../core/governance/adoption/correspondence.json) maps the selected provisions to this engine's actual consumers and limits.

The current receiving aligns the carried scope, authority, verification, correction, continuity, credit and privacy instructions with the source's evidence-applicability and correction rules. Both the synchronous carried manifest and the corresponding runtime modules carry the same instruction. Ground Zero remains the canonical owner of the underlying provisions; Illuci owns these adapters.

| Boundary | Actual engine standing |
|---|---|
| Verification and evidence applicability | Carried into non-raw dispatch context. This does not run tests or make a reported result true. |
| Selected consequential creation | Pre-dispatch source-fit facts are checked through the applicable hard gate. Missing required facts or gate code refuses that selected operation. |
| Ordinary policy loading | Existing ordinary missing-Bill behavior is distinct from selected creation's stricter boundary. It is not universal unbypassable enforcement. |
| Secret and tool controls | Actual checks retain their configured effect boundaries and audited override behavior. A policy sentence alone is not a universal prevention claim. |
| Output review and memory | The implemented SDK consumers can use sourced review and admitted context. Context custody and caller authority remain host responsibilities. |
| Continuous improvement | Retained observations can influence the implemented next action. A suggestion, metric or log entry alone is not proof of an improvement. |

An integration can pass an explicit, source-pinned `policyInputs` list to the output-review adapter. Each item names an ID, a local file path and its expected SHA-256. The loader verifies those bytes before using them as reference material. The host selects and authorizes the source; the digest only establishes identity.

When Ground Zero changes, compare the changed provisions with the affected engine mechanisms. Update this project's selected source record and adapters deliberately, test the affected path, and send useful findings back to Ground Zero. Repeatedly importing a document without changing or observing its consumer does not establish adoption.

This demonstrates the selected pre-dispatch control path, not the factual truth of a caller's adequacy judgment, authenticated permission, a filesystem creation, a live model result or universal enforcement. No network request or model inference occurred in the check. Ordinary missing-policy behavior, explicit audited overrides, and other entry points keep their separate contracts and limits.

The carried-input receiving also checked the selected source adapters, including Standards 6 and 10, reach the actual governed input and that their carried manifest and module texts agree. Raw input remains raw. That proves instruction propagation; it does not prove that a subsequent model will follow the instruction or that a task has been verified.


The version recommendation path also separates review reach from delivery credit. A hub or substrate location no longer promotes a correction to progress credit. The real ceiling consumer requires evidenced scope for its recommendation: correction, unfinished-feature progress, completed feature, or an explicitly selected completed grouping. Contract and policy review still have their own responsibilities; they do not manufacture an epoch or a major release. The helper changes no version file, and a supplied reference is not verification of the underlying facts or authority.

Ground Zero's current attribution amendment is received through the contribution and publication workflow. The Constitution and the previously exercised Standards 6, 10 and 14 are unchanged by that amendment; their existing instruction-propagation and actual dispatch-path evidence remains applicable to those clauses. This source-record update adds no native or universal enforcement claim.
